# AI Therapist Chatbot

## Overview

This project explores the development of an AI-based therapist chatbot designed to provide supportive and empathetic conversational responses.

The objective is to investigate the application of Natural Language Processing (NLP) techniques in mental health support systems.

## Tools Used

* Python
* Natural Language Processing (NLP)
* Text Preprocessing
* Machine Learning
